ebdfy design system

Every part is an e-* tag. v2.css draws each tag in the first frame, and v2.js, loaded with defer, builds the native control inside it. 

<link rel="stylesheet" href="https://cdn.ebdfy.com/ui/v2.css" />
<script type="module" src="https://cdn.ebdfy.com/ui/v2.js"></script>

TypeScript gets every tag from import '@ebdfy/ui/v2', and React 19 from import type {} from '@ebdfy/ui/v2/react'.
