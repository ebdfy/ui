Foundations

The Ink tokens every component reads: colour, type, spacing, radii, depth and icons. Each one is a CSS custom property on :root, and an element with data-theme takes that theme for its subtree.

Motion

Overlays ease in and close at once. With prefers-reduced-motion: reduce nothing moves.

Token Value Use
--eb-duration-fast Menus, popovers and tooltips: fade in and rise 4 px
--eb-duration-base The phone sheet slides up and a toast fades in
--eb-ease-out The curve every entry follows

Icons

eb-icon draws one of these Lucide icons at 16 px, or 20 px with size="20", in the colour around it with a 1.5 px stroke. An app's own <svg> inside eb-icon is drawn the same way. Give an icon that stands alone a label. 

<eb-icon name="truck"></eb-icon>
<eb-icon name="truck" size="20" label="Shipped"></eb-icon>

Tones

One tone list for eb-badge, eb-banner, eb-menu-item, a toast (ebdfy.toast(message, { tone })) and the courier status. A menu item and a toast colour only danger.

Tone Badge Use
neutral Neutral The default: no colour of its own
info Info A note; reads as neutral, since the accent marks interaction only
success Success Done or paid: green
warning Warning Needs a look: the amber of New
danger Danger Failed, risky or returned: red

An order's state goes in eb-badge status, which wins over a tone beside it.

Status Badge Look
new New The warning look: a soft amber pill
confirmed Confirmed A neutral dot
shipped Shipped A teal dot
paid Paid A green dot
returned Returned The danger look: a filled red pill

The 1.0.0 names still work until 2.0 and draw as before: badge attention is warning, critical is danger and shipped is status="shipped"; menu item default is neutral and critical is danger; a toast's error: true is danger.
