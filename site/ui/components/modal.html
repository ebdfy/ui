Modal

e-modal is a dialog that holds a task until the person closes it. In markup it is closed and takes no room. A page opens it with ebdfy.modal.show(id) and closes it with ebdfy.modal.hide(id), where id is the modal's id. Set size to small or large; medium is the default, and on a phone every size is a sheet at the bottom. Put buttons in the footer with slot="footer". The modal fires e-modal-open and e-modal-close, which bubble.

With JavaScript off the buttons below do nothing and the modals stay closed; the code under each example shows the markup.
