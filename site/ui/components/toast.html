ebdfy design system

Toast

An app shows a toast with ebdfy.toast, and the Admin chrome draws it. In the frame below, open More and press Duplicate to see a toast with Undo. Cancel order shows an error toast.

A message is up to 120 letters. It stays for 5 s, and only one shows at a time. An error stays until it is dismissed. A toast carries one action at most.

The toast is fixed to the foot of the window, so it shows at the bottom of this page, not inside the frame.

The chrome's own words (such as Dismiss) follow the page's lang, not the language row below. The row changes only this page's own strings.
