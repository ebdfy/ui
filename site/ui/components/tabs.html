Tabs

eb-tabs holds one eb-tab per filter of a list, underlined when selected, with a count after its label. Set label on the tabs to name them and value to the selected tab's value; a tab's count is optional. The arrow keys move between tabs, and Enter or Space selects. It sends eb-change with the new value when a person picks another tab, and nothing when you set value yourself.
