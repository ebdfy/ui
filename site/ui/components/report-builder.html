Report builder

e-report-builder lets a staff member build a report from a metric, a group-by, filters and a date range, and shows the result as a table or a chart as soon as a choice changes. It holds two cards: Build it, marked data-part="build", and Result, marked data-part="result". When there is room they sit side by side, Result on the left; when there is not, Build it comes first.

Each filter is an e-report-filter whose name is the field it posts and whose label names the dimension. It holds one hidden checkbox per value, ticked when the value is in the filter, so the form posts the ticked values as repeated fields and a page without JavaScript still reads them. A filter with a ticked value shows as a chip, "Channel is Facebook, Messenger"; pressing the chip opens its values again and its x clears them. The button marked data-part="add-filter" opens a picker of the dimensions with nothing ticked and goes when every one is used. The div marked data-part="custom" holds From and To, shown only while the range is Custom; a range over 366 days, or a To before From, is refused under To before anything is asked.

On each change to a choice other than the name, the builder asks the address in result with the form's fields as a query and puts the answer in place of its e-report-result. A later change wins over an earlier answer; while it waits the old result stays under a loading bar, and a failed answer keeps it with Try again. Chart and Table write the hidden field view, which the address reads to answer with an e-chart or an e-table. Inside a save bar form, Discard puts the choices back and asks again.
