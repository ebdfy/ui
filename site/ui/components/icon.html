Icon

e-icon draws a small icon from the kit's sprite. Pick it with name. It is 16 px, or 20 px with size="20". An icon is decorative, so name the button it sits in.

v2.js fetches the sprite from beside itself. A page that runs it from somewhere with no folder, such as a blob: URL, names the files instead: <meta name="ebdfy-icons" content="…/icons.svg"> for the sprite and <meta name="ebdfy-areas" content="…/areas.json"> for the district picker's upazilas.
