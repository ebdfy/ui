ebdfy design system

Button group

eb-button-group keeps related buttons together in one row. label names the group for a screen reader. When the row is too narrow, the buttons wrap to a new line instead of running off the screen.

English বাংলা
Confirm Book courier Print labels 
<eb-button-group label="Order actions">
  <eb-button>Confirm</eb-button>
  <eb-button variant="secondary">Book courier</eb-button>
  <eb-button variant="ghost">Print labels</eb-button>
</eb-button-group>
