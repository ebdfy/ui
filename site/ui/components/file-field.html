File field

e-file-field picks one file to upload, such as a CSV of products to import. Write its <input type="file"> inside the tag, so the form posts the file before the script and with it off. The script puts the input in one bordered row with Choose file, then shows the chosen file's name, its size and, for a CSV, how many rows it holds under its header line.

accept and max-size, in bytes, say what the page takes: another kind or a larger file is refused under the field, and the input is emptied, so the form never posts it. The row count is read in the browser; a line break inside quotes stays in its row, and a byte order mark is no data.
