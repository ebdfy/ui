Menu

eb-menu opens a list of actions from the eb-button in its trigger slot. Each action is an eb-menu-item. Set tone="danger" on a risky one, an eb-icon in slot="icon" before its words, and shortcut to show its keys, one per chip, at the end of the row. Pick keys the browser does not use for itself: Ctrl+D, Ctrl+P and Ctrl+N bookmark, print and open a window, so these samples use Alt+Shift. The arrow keys move between items, Enter picks one and Escape closes the menu. The page shows Ctrl and Alt here and ⌘ and ⌥ on a Mac or iPhone.
