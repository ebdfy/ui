Button

eb-button runs an action. Use variant="primary" for the one main action of a card, and the default secondary for the rest. A button is as wide as its label; full-width makes it fill its row, as two equal actions in a bar do. A toggle, such as the current filter, sets pressed to true or false, so a screen reader hears whether it is on.
