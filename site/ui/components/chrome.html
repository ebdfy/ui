ebdfy design system

Admin chrome

eb-admin-chrome frames an app in the Admin: the title bar, the navigation and the app itself. The app sets its title and its own entries with ebdfy.title and ebdfy.nav. The frame below shows the sample app's orders list.

In a window 600 px wide or more the navigation is a 236 px sidebar, with the app's own entries under its name and the title bar beside it. In a narrower window the navigation is a tab bar along the bottom and the app's entries are a strip under the title bar.

Limits: a title up to 60 characters, 2 title actions, and up to 8 navigation entries of 24 characters each.

The chrome's own words (Discard, Save, Dismiss, Close) follow the page's lang, not the language row below. The row changes only the three links slotted into the chrome and this page's own strings.

In the app

ebdfy.title('Order #1001', { actions: [{ label: 'Book courier', onAction: book }] })
ebdfy.nav([
  { label: 'Orders', path: '/' },
  { label: 'Order #1001', path: '/order' },
])

In the host page

<eb-admin-chrome
  app-name="Sample app"
  src="https://sample.example.com/?store=demo"
  token-url="/dev/id-token?app=sample"
  api-url="/dev/graphql"
  stores-url="/stores"
>
  <a slot="nav" href="/orders" aria-current="page">Orders</a>
  <a slot="nav" href="/products">Products</a>
  <a slot="nav" href="/customers">Customers</a>
</eb-admin-chrome>
