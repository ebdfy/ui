Index table

e-index-table holds many records in one card: view tabs, a toolbar, a table and a pager. It also keeps the selection. Put an e-checkbox in each row's first cell and one in the head row. Ticking rows shows how many are selected and your slot="bulk" actions in place of the toolbar. Below 600 px the rows are flat lines: a cell's card attribute puts title and end on the first line, body and status on the second, meta and aside on the third. When the table has no rows, an e-empty-state you add takes its place.

Select mode on a phone

Below 600 px no checkbox shows until the list is in select mode. The index table adds a Select button to the toolbar once its rows hold checkboxes, and a long press on a row also starts select mode and ticks that row. In select mode every row shows its checkbox, and the bulk bar takes the toolbar's place with a Select all checkbox, the count, your actions and a Done button. Done, or removing the select-mode attribute, unticks every row and hides the checkboxes again. From 600 px the checkboxes always show.

On a phone the search field shares its line with the button written right after it and the kit's Select, so write Add filter straight after the search field, with an e-icon, and the chips after Add filter. A toolbar button with an icon shows only its icon on a phone, its words kept for screen readers. In select mode a tap on a row ticks it.
