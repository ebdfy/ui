Index table

e-index-table holds many records in one card: view tabs, a toolbar, a table and a pager. It also keeps the selection. Put an e-checkbox in each row's first cell and one in the head row. Ticking rows shows how many are selected and your slot="bulk" actions in place of the toolbar. Below 600 px each row becomes a card. When the table has no rows, an e-empty-state you add takes its place.
