Rich text

e-rich-text writes a body of formatted text, such as a page's content or a product's description. The body's HTML is the value of the <textarea> written inside the tag, which joins the form, so the form posts the HTML before the script and with it off, when the text area shows it to edit by hand.

The script draws one bordered box under the label: a toolbar of Bold, Italic, Underline, Heading, List, Quote, Link, Image and Show HTML, then a body that grows from 240 px. Each button reads pressed where the caret sits. Every edit writes the body's HTML to the text area and fires input, so the save bar counts it; undoing back to the opening body leaves the opening HTML, as written, so nothing is left to save. On a phone the toolbar scrolls sideways rather than wrap.

The body keeps only the toolbar's own formatting: paragraphs, strong, em, u, h2, a ul list, blockquote, links and images. A paste from a web page loses its styles, classes and scripts, and a link or image address must be http or https, or a path on the store. The API cleans the HTML again as it saves it.
