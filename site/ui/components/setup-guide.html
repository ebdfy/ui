Setup guide

e-setup-guide lists the steps to set up a store. Each e-setup-step has a tick; a ticked step has done, which the tick sets and clears and a page may set too. The guide shows a count such as “2 of 5” and a Dismiss button. Dismiss fires dismiss, which bubbles (a page listens on the guide itself), and removes the guide; the page keeps the choice.
