Text field

e-text-field takes one line of text. Its native input joins the form it sits in. Set type and inputmode for email, phone or URL keyboards. Write the input inside the tag and the form shows its fields and posts before the script, and with it off; the script adopts it. Write a label for the input too and the field is named before the script; the script keeps that label and the input's id. Typing in a field clears its error.
