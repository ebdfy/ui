Pagination

eb-pagination moves between pages of orders by cursor, so it knows only whether a page exists on each side. Set has-previous and has-next; a button without its page is disabled. It sends eb-previous and eb-next when a button is pressed.

English বাংলা

Orders 21 to 40, with pages on both sides. 

<eb-pagination has-previous has-next></eb-pagination>
